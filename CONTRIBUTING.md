# Contributing to Shipmate Open Source

Contributions are welcome across all repositories under `github.com/Shipmate-agency`.

## Guidelines
1. Keep changes focused, tested, and dependency-free where the repo is zero-dependency.
2. Never commit real credentials, private customer data, or exploit payloads targeting third-party systems.
3. For `awesome-vibe-code-security`, include objective one-line descriptions and prefer open-source tools or official docs.
4. Run the repository's unit tests (`python3 -m unittest`) before opening a PR.
